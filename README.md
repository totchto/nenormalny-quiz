# Ненормальный квиз — сайт с отдельными страницами игр

Статический сайт для GitHub Pages: **каталог → страница конкретного квиза → вопросы**. Есть два квиза по архиву «Ненормальная группа», всего 50 вопросов. Общий движок и стили; никаких платных API, сервера или базы данных.

## Адреса после публикации

- Каталог: `https://totchto.github.io/nenormalny-quiz/`
- «Ненормальная группа 2»: `https://totchto.github.io/nenormalny-quiz/quizzes/nenormalnaya-gruppa-2/`
- «Перепись ненормальных»: `https://totchto.github.io/nenormalny-quiz/quizzes/perepis-nenormalnyh/`

Прежние ссылки из старой одностраничной версии вида `/?quiz=nenormalnaya-gruppa-statistika` перенаправляются на новую страницу.

## Структура

```text
index.html                             Главная страница — каталог
quizzes.json                           Метаданные всех игр для каталога
assets/style.css                       Общие стили
assets/catalog.js                      Код каталога
assets/quiz-engine.js                  Единая логика игры для любого набора вопросов
quizzes/
  nenormalnaya-gruppa-2/
    index.html                          Самостоятельная страница игры
    questions.json                     25 вопросов «Ненормальной группы 2»
  perepis-nenormalnyh/
    index.html                          Самостоятельная страница игры
    questions.json                     25 вопросов «Переписи ненормальных»
tools/
  quiz-template.html                   Шаблон новой страницы
  add_quiz.py                           Установка нового квиза из JSON
  refresh_catalog.py                    Проверка вопросов и обновление каталога
tests/test_site.py                      UI-тесты (только для разработки)
.nojekyll                               Файл для корректной публикации статического сайта
```

Каждая игра имеет собственный постоянный URL. Новая игра не требует копирования движка или CSS.

## Обновление существующего GitHub-репозитория

Репозиторий: <https://github.com/totchto/nenormalny-quiz>

**Нужно загрузить всё содержимое этого архива**, включая вложенные папки. Одного `index.html` теперь недостаточно, поскольку каталог и страницы подгружают JSON и JS.

### Надёжный способ через Terminal на Mac

1. Скачайте ZIP с проектом и распакуйте его.
2. Откройте Terminal и выполните:

```bash
git clone https://github.com/totchto/nenormalny-quiz.git
cd nenormalny-quiz
```

3. Скопируйте **содержимое распакованной папки**, а не саму папку, в этот каталог (заменив существующий `index.html`). Например:

```bash
cp -R /путь/к/распакованной/папке/. .
```

4. Отправьте изменения:

```bash
git add -A
git commit -m "Разделить каталог и страницы квизов"
git push origin main
```

При первом `git push` GitHub может запросить вход через менеджер учётных данных. Пароль аккаунта вместо токена для Git через HTTPS не принимается.

### Настройка GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**. Укажите `main` / `/(root)`, нажмите **Save**. Если Pages уже включён, менять настройку не требуется. После загрузки файлов дождитесь завершения публикации. Адрес сайта указан выше.

> Если есть предыдущая версия `index.html`, она будет заменена. Локальный прогресс игроков сохранится, потому что адрес сайта, идентификаторы квизов и ключи хранения не меняются.

## Как добавить третий, четвёртый и любые следующие квизы

**1.** Подготовьте новый `questions.json` по образцу `quizzes/nenormalnaya-gruppa-2/questions.json`.

Верхние поля:

- `id` — неизменяемый идентификатор игры;
- `slug` — адрес на латинице (`kino-i-serialy`);
- `title`, `subtitle`, `description` — тексты для каталога и страницы игры;
- `category`, `difficulty`, `durationMinutes`, `edition` — подписи;
- `storagePrefix` — уникальный префикс сохранений, например `kino-i-serialy`;
- `version` — целое число, начиная с `1`;
- `rounds` — массив раундов; внутри `questions` — вопросы.

Форматы вопросов:

```json
{"type":"choice","question":"Вопрос?","choices":["А","Б","В","Г"],"correct":2,"explanation":"Почему","source":"Источник","joke":"Шутка"}
```

или

```json
{"type":"text","question":"Кого назвали?","answers":["Женя","Евгения"],"displayAnswer":"Женя","explanation":"Почему","source":"Источник","joke":"Шутка"}
```

**2.** На компьютере в корне проекта выполните:

```bash
python3 tools/add_quiz.py /путь/к/новому/questions.json
```

Команда автоматически создаст `quizzes/<slug>/index.html`, скопирует JSON и обновит `quizzes.json` (каталог). **Не надо редактировать общий движок или страницу каталога.**

**3.** Залейте изменения на GitHub (`git add -A`, `git commit`, `git push`). Через некоторое время карточка появится на сайте.

Если нужно исправить вопросы **уже существующего** квиза, отредактируйте его `questions.json`, затем выполните `python3 tools/refresh_catalog.py`. Если изменения влияют на сложность или результат, увеличьте `version`, чтобы новая версия получила отдельные сохранения и рекорды; прежние останутся в браузере, но больше не будут отображаться в обновлённой версии.

## Локальный запуск

Файлы используют `fetch()` для загрузки JSON. Поэтому для проверки нужен локальный HTTP-сервер; открытие `index.html` двойным щелчком через `file://` может не загрузить список игр.

```bash
cd nenormalny-quiz-pages
python3 -m http.server 8000
```

Откройте <http://localhost:8000/>. Для проверки UI есть `python3 tests/test_site.py` (необязательные зависимости: `pip install playwright beautifulsoup4` и Chromium).

## Сохранение и приватность

- Игра запоминает прогресс, выбранные варианты и рекорд в `localStorage` на **каждом устройстве отдельно**. Ключи двух прежних игр сохранены (`nenormalny-quiz-2:*:v1` и `nenormalny-quiz-stats:*:v1`).
- Счёт и ответы не отправляются на сервер; общего рейтинга нет.
- В репозиторий попадают только вопросы и статистика, **не исходные Telegram-архивы**. При этом сами цитаты, имена и ответы находятся в публичных JSON-файлах и доступны любому посетителю, включая того, кто умеет смотреть исходный код. Убедитесь, что участники согласны с публикацией.
- Подсчёт мата в статистическом квизе условный: поиск по ограниченному словарю, без определения контекста.
